# Air-Ink Dataset

## 1. Manual Dataset

- Total images: 200
- Classes: digits 0 through 9
- Samples per class: 20
- Format: PNG
- Image dimensions: 28x28 pixels
- Color mode: Grayscale
- Additional metadata: JSON files
- Collection method: Manual handwriting capture

All manual samples were collected from a single writer.
Therefore, this dataset should not be considered representative of
different writers or a general population.

## 2. Synthetic Dataset

- Total images: 3000
- Classes: digits 0 through 9
- Samples per class: 300
- Format: PNG
- Image dimensions: 28x28 pixels

These images are synthetically generated and are not genuine
handwritten samples. They are intended for auxiliary experiments.

## 3. Important Notes

The manual and synthetic datasets must be evaluated separately.
Synthetic samples must not replace genuine handwritten data
in independent test evaluation.

## 4. Project

Air-Ink: Air Writing Recognition using hand tracking
and machine learning.
